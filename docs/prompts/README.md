# Prompt templates

Copy a prompt, fill in the `[brackets]`, and give it to any AI coding assistant working in this repo. Each prompt points the model at `AGENTS.md`, keeps it to the files that matter, and makes it run `npm run check` before it finishes.

| Prompt | Use it to |
|---|---|
| [add-daily-entry.md](add-daily-entry.md) | Add today's quote, track, or note |
| [add-project-post.md](add-project-post.md) | Write or publish a project, idea, or accolade post |
| [edit-home-sections.md](edit-home-sections.md) | Add, reorder, hide, or edit home page sections |
| [update-resume.md](update-resume.md) | Fill in about, experience, education, skills, links, résumé PDF |
| [new-section-type.md](new-section-type.md) | Create a new kind of home section |
| [add-post-type.md](add-post-type.md) | Add a new collection, like Notes |
